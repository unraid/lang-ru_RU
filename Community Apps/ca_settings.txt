Support Thread=Тема поддержки
Hide Deprecated Applications=Скрыть устаревшие приложения
This setting hides deprecated applications from the list of available apps Deprecated apps will still however display within the installed and previous apps sections=Эта настройка скрывает устаревшие приложения из списка доступных. Однако устаревшие приложения по-прежнему будут отображаться в разделах установленных и предыдущих приложений
Hide Incompatible Applications=Скрыть несовместимые приложения
This setting will hide applications that are listed as being incompatible with your version of Unraid=Эта настройка скроет приложения, отмеченные как несовместимые с вашей версией Unraid
Allow install of second instance=Разрешить установку второго экземпляра
This option enables another button on the cards and popups which will allow you to reinstall an installed application using its default template values This option can be confusing at times, and is only generally used if you wish to install and have an application running twice simultaneously=Эта опция добавляет ещё одну кнопку на карточках и во всплывающих окнах, которая позволяет переустановить установленное приложение с использованием значений шаблона по умолчанию. Эта опция иногда может сбивать с толку и обычно используется только в том случае, если вы хотите установить и запустить приложение одновременно дважды
Automatically open the sidebar=Автоматически открывать боковую панель
Allows CA to automatically open the sidebar for more information when hovering over an application's icon=Позволяет CA автоматически открывать боковую панель с дополнительной информацией при наведении курсора на значок приложения
Allow CA to check for updates to applications=Разрешить CA проверять обновления приложений
This setting enables CA to check for updates to applications Note that Community Applications will always check for updates to itself=Эта настройка позволяет CA проверять обновления приложений. Учтите, что Community Applications всегда будет проверять обновления для себя
Disable Mouse Wheel Page Changes=Отключить смену страниц колесом мыши
This setting disables using left or right on a mouse wheel to change the page=Эта настройка отключает использование наклона колеса мыши влево или вправо для смены страницы
Mouse wheel threshold=Порог колеса мыши
If you tilt the mouse wheel left or right, the browser returned value will change Set the threshold to the value returned Note that different browsers and operating systems may return different values=Если вы наклоняете колесо мыши влево или вправо, возвращаемое браузером значение будет меняться. Установите порог равным возвращаемому значению. Учтите, что разные браузеры и операционные системы могут возвращать разные значения
This is a global value for all devices If it causes issues, then disable Mouse Wheel Page Changes=Это глобальное значение для всех устройств. Если это вызывает проблемы, отключите «Отключить смену страниц колесом мыши»
Allow CA to send any emergency notifications=Разрешить CA отправлять экстренные уведомления
This setting allows CA to periodically scan your system and alert you to the presence of=Эта настройка позволяет CA периодически сканировать вашу систему и предупреждать вас о наличии:
1 Known malware and security vulnerabilities within applications=1. Известного вредоносного ПО и уязвимостей безопасности в приложениях
2 Critical security vulnerabilities within Unraid OS=2. Критических уязвимостей безопасности в Unraid OS
3 Any installed applications which may seriously hinder the operation of your server=3. Любых установленных приложений, которые могут серьёзно затруднить работу вашего сервера
Save CA debugging information=Сохранять отладочную информацию CA
Only enable this when advised to from the author of Community Applications=Включайте это только по рекомендации автора Community Applications
Enable developer mode=Включить режим разработчика
This unlocks some extra features within CA generally only used by developers Not recommended to enable=Это разблокирует некоторые дополнительные функции в CA, которые обычно используются только разработчиками. Не рекомендуется включать
